#### 9. Dual-Mode Real-Time Multi-Computer Sync Engine (3 to 4 Workstations)
- **Unified Sync Manager (`sync_manager.js`)**:
  - Replaces isolated localStorage calls with an enterprise data layer abstraction.
  - Maintains instant zero-lag local mirrors in **IndexedDB** and **localStorage** so the UI is instantaneous even during network disconnects.
- **Three Interchangeable Synchronization Modes (Top Header Toggle)**:
  - **Mode A: Cloud Real-Time Sync (Firebase Firestore)**:
    - Real-time `onSnapshot` listeners synchronize all patient registrations, test entries, edits, and deletions across any number of computers or remote clinics.
    - Built-in offline persistence automatically caches records locally and syncs them once internet returns.
  - **Mode B: Local LAN Real-Time Sync (Offline Clinic Wi-Fi / Local Network)**:
    - Zero-internet operation powered by companion Node.js LAN server (`lan-server.js`).
    - Bidirectional WebSocket broadcasting (<5ms latency across local Wi-Fi) immediately propagates updates to all 3–4 clinic computers.
  - **Mode C: Local Browser Only (Fallback)**:
    - Standalone mode saving exclusively to local computer IndexedDB and localStorage.
- **Multi-Computer Conflict Prevention & Atomic Bill Numbering**:
  - Unique workstation identifiers (e.g. `PC-1 Reception`, `PC-2 Doctor USG`, `PC-3 Pathology Lab`, `PC-4 Billing Counter`).
  - Atomic counter sequencing via `/api/next-bill-number` eliminates duplicate voucher number collisions.
  - Pre-save collision detection: if another workstation assigned the same number in parallel, the engine auto-advances to the next sequential voucher and alerts the operator.
- **Seamless Data Merging & Reconciliation**:
  - Switching between Cloud and LAN modes triggers an automatic two-way merge using unique record IDs and `updatedAt` timestamps.
  - **"🔄 Force Sync All Records"** button for manual instant reconciliation.
  - **"📥 Export / 📤 Import Clinic Backup (JSON)"** for complete 1-click clinic database preservation.
- **Live Notifications & Diagnostic Dashboard**:
  - Pulsating top-bar status badges: `🟢 Live Sync Active - Cloud`, `🟢 Live Sync Active - LAN`, `💾 Local Browser Only`.
  - Subtle real-time toast notifications whenever another computer registers or updates a patient (e.g. *"🖧 PC-2 registered patient: Ramesh Chand Sharma (#NWR/2026-27/00143)"*).

### How to Run Locally & Across Multiple Computers

#### Single Computer Standalone Mode:
You can run the application directly by opening `index.html` in any web browser (Chrome, Edge, Firefox, Safari):

```powershell
# Open directly:
Start-Process index.html

# Or via Python HTTP server:
python -m http.server 8085
# Then navigate to: http://localhost:8085
```

#### Multi-Computer Local LAN Real-Time Sync Mode (3–4 Computers on Clinic Wi-Fi):

1. **On your Main/Host Computer:**
   - Double-click **`start-server.bat`** (or open terminal and run `node lan-server.js`).
   - The server will display the primary Local Wi-Fi IP address, e.g.:
     ```
     >>> CONNECT OTHER COMPUTERS ON YOUR CLINIC WI-FI / LAN:
         • Primary LAN URL:   http://192.168.1.100:3000
         • On this Host PC:   http://localhost:3000
     ```

2. **On the Other Computers (Reception, Doctor's USG Room, Lab, Billing):**
   - Open any web browser and go to `http://192.168.1.100:3000` (replace with your host PC's IP).
   - Alternatively, open your local `index.html`, select **"🖧 Local LAN Server"** from the top header dropdown, and enter the Host IP in **"⚙️ Sync Settings"**.
   - All patient registrations, test additions, billing edits, and deletions will immediately reflect across all screens in real time without refreshing the browser!

#### Cloud Real-Time Sync Mode (Firebase Firestore):
1. In the top navigation bar, select **"☁️ Cloud Sync (Firebase)"**.
2. Click **"⚙️ Sync Settings"**.
3. Paste your Firebase configuration object into the Quick Paste box and click **"✨ Auto-Fill Fields"**.
4. Click **"🔌 Test Firebase Connection"** and **"💾 Save & Apply"**.
5. All connected computers will sync globally across the internet in real time.
